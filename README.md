# Входящ контрол

Отделен софтуер за дневник на приетите храни. Качваш фактура или стокова, системата пълни партидите, ти записваш и печаташ дневника.

Не е вързан към кухнята на ЛакомникЪ. Има си собствена база и вход.

## Пускане на този компютър

Нужен е Node.js 22.13 или по-нов.

```
cd "05-vhodqsht-kontrol"
npm install
npm --prefix server install
npm --prefix client install
npm run dev
```

Отвори http://127.0.0.1:5175

Локален вход: потребител `intake`, парола `stef88`.

За постоянно ползване (без Vite):

```
npm run setup
npm start
```

Тогава е на http://127.0.0.1:3003

## За другата фирма

В `server/.env` или в средата на машината:

```
INTAKE_USER=sklad
INTAKE_PASS=сложи-дълга-парола
SITE_NAME=Tokyo sushi
SITE_PLACE=
INTAKE_AI_KEY=ключ-от-Google-AI-Studio
```

`SITE_NAME` и `SITE_PLACE` излизат в заглавието на печатния дневник. Сега е Tokyo sushi.

`INTAKE_AI_KEY` е безплатен Gemini ключ. Без него можеш да поставяш текста ръчно или да разчиташ снимки с OCR на Windows.

## Какво прави

- Чете фактури и стокови разписки (снимка, PDF или текст)
- Пълни L-номер / партида, количество, годност
- Решение приема се / отказва се
- Дневник за печат на А4 пейзаж

Не пипа склад, рецепти и онлайн магазин.
